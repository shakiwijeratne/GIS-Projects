# Thalawa Divisional Secretariat Division & Kaluaggala Grama Niladhari Division – GIS Map Digitization

## Overview

This project focuses on digitizing geographic features within the **Thalawa Divisional Secretariat Division (DSD), Anuradhapura District, Sri Lanka**, using a 1:50,000 topographic map as the primary reference.

The project involves converting geographic information represented on a printed topographic map into digital spatial data using GIS software. The digitized features are organized into spatial layers and used to create a digital representation of the study area.

## Objectives

- Digitize geographic features from a topographic map.
- Create and organize spatial datasets using appropriate geometry types.
- Represent roads, water bodies, agricultural lands, and other geographic features as digital GIS layers.
- Apply appropriate cartographic symbology and labeling techniques.
- Develop practical skills in GIS data creation, editing, and map visualization.

## Tools & Technologies

- **ArcGIS Desktop – ArcMap 10.8**
- Geodatabase for spatial data management
- GIS digitizing and editing tools
- Cartographic visualization and annotation tools

## Methodology

1. Referenced the topographic map of the study area.
2. Identified and interpreted geographic features represented on the map.
3. Created appropriate spatial datasets according to feature geometry.
4. Digitized geographic features using ArcMap editing tools.
5. Organized spatial data into feature classes.
6. Applied cartographic symbology, labeling, and annotation.
7. Reviewed digitized features for spatial consistency and visual accuracy.

## Cartographic Representation

Different symbology and text styles were used to improve map readability and distinguish geographic features.

- Feature-specific symbology for different geographic layers.
- Differentiated text styles for place names and geographic labels.
- Annotation for greater control over label placement, size, color, and orientation.
